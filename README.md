# Simple Sales Dashboard 📊

## 📌 Project Overview
The **Simple Sales Dashboard** is an Excel-based data analysis project created to analyze sales performance across different regions. It presents key business metrics and visualizations to make sales data easier to understand.

## 🎯 Project Objectives
- Analyze overall sales performance.
- Calculate total sales, total profit, and units sold.
- Compare sales across different regions.
- Present data through charts and a dashboard.

## 🛠️ Tools Used
- Microsoft Excel
- PivotTables
- Charts and Data Visualization

## 📈 Key Performance Indicators (KPIs)
- **Total Sales:** 2,297,200.86
- **Total Profit:** 286,397.02
- **Units Sold:** 37,873

## 📊 Dashboard Features
- KPI summary for sales, profit, and quantity.
- Regional sales comparison.
- Interactive PivotTable-based analysis.
- Clear and easy-to-understand visualizations.

## 📂 Project Files
- `Sales_Dashboard.xlsx` — Excel workbook containing the sales data and dashboard.

## 💡 Key Insights
- The West region recorded the highest sales.
- The East region had the second-highest sales.
- The South region recorded the lowest sales.
- The dashboard helps compare regional performance quickly.

## 🚀 How to Use
1. Download `Sales_Dashboard.xlsx` from this repository.
2. Open the file using Microsoft Excel.
3. Explore the dashboard and regional sales chart.
